Load engine (Bucket 2)

Match-to-match, per player. Int = HSR per minute (intensity, minutes-adjusted). Vol = total HSR (volume). Base = rolling average of the player's last 4 matches. Ratio = latest match ÷ baseline (spotting a spike above their own norm). Int Δ = change vs previous match.

Bucket 2 is the maths only — no colour flags yet. A player needs 3+ prior matches before the ratio is trustworthy (flagged "building baseline"). Sanity-check the numbers, then Bucket 3 turns this into the green/amber/red read.
